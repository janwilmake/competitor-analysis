## Market Context Notes (April 2026)

1. **Category is very new:** The AEO/GEO tool category is ~18–24 months old. Tools are still finding product-market fit. Differentiation claims are often more marketing than fully realized product.

2. **The execution gap is real and unfilled:** Most tools show dashboards — buyers frequently report knowing *what* is happening but not *what to do about it.* Profound Workflows is the first serious attempt to bridge this. Promptwatch's content optimization tab is early-stage. Vismore (new entrant) claims to go further.

3. **Horizontal platform threat is large:** Ahrefs and Semrush's distribution is enormous. Any SEO team already paying for those platforms will default to the built-in AI toolkit first. Promptwatch must win on feature depth (crawler logs, source-level data) or agency-specific workflows that the SEO giants don't prioritize.

4. **Data quality varies wildly:** Some tools query AI platforms directly via API; others scrape web interfaces. API access provides more accurate, reproducible results. This is a meaningful quality difference buyers are starting to care about.

5. **Geography matters:** Between 40–60% of AI-cited sources change month-to-month. Regional visibility can differ dramatically by market. Tools with robust geo-filtering (Peec, Omnia, SE Ranking) are valuable for multi-market brands.

6. **Promptwatch's crawler log feature is unique:** No other tool in this competitive set tracks AI crawler logs to show exactly which pages AI engines are visiting and citing. This is a meaningfully differentiated capability that the team should invest in and market more aggressively.
